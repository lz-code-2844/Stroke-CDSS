# Literature Knowledge-Base Files

## Copyright and licensing notice

Due to copyright and licensing restrictions associated with bibliographic databases and published literature, this public repository does not redistribute abstracts, full text, author information, journal metadata, or downloaded literature datasets. The Excel files in this directory provide only the `PMID` and `Title` column structure as templates.

To build the RAG knowledge bases, users should populate these templates locally using literature records obtained from lawful and appropriately licensed sources. Users are responsible for complying with the terms of use and licensing requirements of the corresponding data providers.
